# מעקב מחירים והנחות בחנויות אונליין בישראל

מעקב יומי אחרי מחירים ו"מחירים לפני הנחה" ב-24 חנויות אונליין, כדי למדוד כמה זמן נמשכות הנחות, והאם המחיר "לפני ההנחה" נגבה אי פעם בפועל.

## איך זה עובד

| שלב | מתי | מה קורה |
|---|---|---|
| איסוף (`collect.yml`) | כל לילה | כל המוצרים מכל חנות נאספים ממאגר הנתונים של האתר (Shopify ‏`/products.json`, WooCommerce Store API, ‏Magento GraphQL). |
| עדכון | באותה ריצה | `data/current/<store>.csv` מחזיק את המצב הנוכחי של כל מוצר, כולל ממתי הוא בהנחה ברציפות (`sale_since`) ומתי נראה לאחרונה במחיר מלא. `data/history/<store>.csv` נרשם רק כשהמחיר משתנה. |
| ארכיון (`archive.yml`) | 3 פעמים ביום | כל מוצר שבהנחה נשמר ב-Wayback Machine פעם בשלושה ימים (שליש מהמוצרים בכל יום, הוותיקים בהנחה קודם). יומן: `data/archive/<date>.csv`. |
| דוח | אחרי כל איסוף | `REPORT.md`: לכל חנות, כמה מוצרים בהנחה, כמה ברצף של 30/60/90 ימים, וכמה מעולם לא נראו במחיר מלא. |

## הסתייגויות

- הנתונים הם מה שהאתר מחזיר במאגר הנתונים, לא בהכרח מה שהקונה רואה. במחסני חשמל המחיר הישן קיים בנתונים בלי להיות מוצג; בשילב ובקוק אנד בייק מוצגות הנחות שלא נמצאות בנתונים. לפני מסקנה על מוצר כדאי לבדוק את הצילום בארכיון.
- הבקשות מזוהות (User-Agent עם קישור לפרויקט), בקצב של בקשה בשנייה לכל אתר, ומכבדות robots.txt.

## הגדרות

- **Secrets** (לא חובה): `IA_ACCESS_KEY`, `IA_SECRET_KEY` — מפתחות S3 של חשבון archive.org (https://archive.org/account/s3.php). בלעדיהם השמירה רצה בלי חשבון, במגבלות נמוכות יותר.
- רשימת החנויות: `stores.json`.
- הרצה ידנית: לשונית Actions → בוחרים workflow → Run workflow.
